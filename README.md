Olist Delivery Performance Analysis

About

This is my data analytics project based on the Olist e-commerce dataset. I wanted to explore how orders are delivered and understand how often deliveries are late.

I'm using this project to practise SQL, Python, and data visualization on real-world data.

Tools I'm Using

- PostgreSQL
- Python (Pandas, Matplotlib)
- Google Colab
- Looker Studio

What I'm Working On

- Checking and understanding the order data
- Using SQL queries to analyze deliveries
- Looking at delivery time and late deliveries
- Exploring monthly trends
- Creating visualizations and a dashboard

Files

- "delivery analysis.sql" – SQL queries
- "Olist_Delivery_Performance_Analysis (1).ipynb" – Python analysis
- "README.md" – Project details

Current Status

I'm still working on this project. The next step is to complete the analysis, check the results, and finish the dashboard in Looker Studio.
